# ValutaTrade Hub

Консольное приложение для симуляции торговли валютами, поддерживающее виртуальные кошельки, историю операций и сервис парсинга актуальных курсов.

## Структура проекта
* `src/valutatrade_hub/core/` — бизнес-логика (модели `User`, `Wallet`, `Portfolio`, исключения, реестр валют).
* `src/valutatrade_hub/infra/` — инфраструктура (Singleton для работы с JSON, настройки).
* `src/valutatrade_hub/parser_service/` — микросервис для получения курсов из внешних API.
* `src/valutatrade_hub/cli/` — консольный интерфейс.
* `data/` — локальное хранилище JSON-файлов (пользователи, кошельки, кэш курсов).
